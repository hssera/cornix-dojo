# Cornix Dojo

自分のキーマップで練習する、[Cornix LP](https://vial.rocks) 専用タイピング道場。

**▶ https://hssera.github.io/cornix-dojo/**

## 特徴

- **キーマップ連動**: WebHID (Vialプロトコル) で実機から読み取り、または `.vil` ファイルをドラッグ&ドロップ。レイヤー・Shiftの押し方まで3色ハイライトで案内
- **キーマップ難度スコア**: レイヤーやShiftのホールドが必要なキーほど高得点（1打10pt＋ホールド+15pt、コンボ倍率 最大×2.0）
- **練習モード**: 日本語ローマ字（ヘボン式/訓令式対応）/ 英単語・英文 / 記号・レイヤー / 苦手キー / ミックス、30・60・90秒＋フリー練習
- **分析と成長記録**: ミス分布ヒートマップ、苦手キー集中練習、プレイごとのWPM履歴グラフ
- **外観カスタム**: 本体カラー4色（シルバー/ブラック/グリーン/オレンジ）、キーキャップの塗り分け、ライト/ダークテーマ

## 構成

`index.html` 単一ファイル・依存ライブラリなし。記録はすべてブラウザの localStorage に保存されます。
